# 设计系统外部链接索引

各公司设计系统的外部链接导航索引：用于参考现成 DS 的设计令牌、组件与规范。仅收录链接与一句简介，不展开方法论（token 架构方法论见本地 `design-system` skill）。溢出条目见 `references/more.md`。

## 主要公司设计系统

- [Google Material Design](https://material.io/design) - Google's design system for intuitive, beautiful products.
- [Microsoft Fluent UI](https://fluentui.microsoft.com/) - Microsoft's open-source cross-platform design system (web/Apple/Android).
- [IBM Carbon](https://www.carbondesignsystem.com/) - IBM's open-source design system for products and experiences.
- [Shopify Polaris](https://polaris.shopify.com/) - Design system for great experiences for Shopify's merchants.
- [Atlassian Design Guidelines](https://atlassian.design/) - End-to-end design language for straightforward, beautiful experiences.
- [Salesforce Lightning Design System](https://www.lightningdesignsystem.com/) - Salesforce's design system for enterprise apps on the Lightning platform.
- [GitHub Primer](https://primer.style/) - Open-source design system powering GitHub's products.
- [GitLab Pajamas](https://design.gitlab.com/) - Resources, components, and design guidelines behind GitLab.

## 设计 tokens 资源

- [Design Tokens W3C Community Group](https://www.w3.org/community/design-tokens/) - W3C community group defining a design tokens format spec.
- [DesignTokens.dev](https://www.designtokens.dev/) - Ship design tokens without managing infrastructure.
- [Style Dictionary](https://github.com/amzn/style-dictionary) - Amazon's build system to define styles once and use them on any platform.
- [Theo](https://github.com/salesforce-ux/theo) - Salesforce's abstraction for transforming and formatting design tokens.
- [Diez](https://diez.org/) - Open-source toolkit for sharing visual styles across codebases and platforms.
- [Figmagic](https://github.com/mikaelvesavuori/figmagic) - Generate design tokens and token-driven React components from Figma.
- [Superposition](https://superposition.design/) - Extract design tokens from websites and reuse them in code or design tools.
- [Design Tokens Validator](https://animaapp.github.io/design-token-validator-site/) - Validate tokens against the Design Token Community Group spec.

## pattern library 资源

- [Storybook](https://storybook.js.org/) - Build UI components in isolation for React, Vue, Angular and more.
- [Pattern Lab](https://patternlab.io/) - Build pattern-driven UIs using atomic design principles.
- [React Styleguidist](https://react-styleguidist.js.org/) - Isolated React component dev environment with a living style guide.
- [Styled System](https://styled-system.com/) - Utility functions adding style props controlled by a global theme object.
- [Stencil](https://stenciljs.com/) - Toolchain for building reusable, scalable design systems as web components.
- [Zeroheight](https://zeroheight.com/) - Document all design system resources in one living styleguide.
- [Backlight](https://backlight.dev/) - Collaborative platform to build, document, and publish design systems in code.

## React 设计系统库

- [Ant Design](https://ant.design/) - Ant Financial - design system for enterprise applications (Nature & Determinacy).
- [Material UI](https://mui.com/) - React components that implement Google's Material Design.
- [Blueprint](http://blueprintjs.com/) - Palantir - React-based UI toolkit for the web.
- [Grommet](http://grommet.io/) - Hewlett Packard - guidance and components from concept to real app.
- [Garden](https://garden.zendesk.com/react-components/) - Zendesk - curated collection of React UI components.
- [Backpack](https://backpack.github.io/) - Skyscanner - design resources and reusable components for Skyscanner products.
- [Ring UI](http://www.jetbrains.org/ring-ui/index.html) - JetBrains - UI building blocks for JetBrains web products.
- [Canvas](https://canvas.hubspot.com/) - HubSpot - the design system HubSpot uses to build its products.
