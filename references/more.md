# 设计系统索引 — 更多条目

SKILL.md 精选之外的条目，按分区补充。来源：[awesome-design-systems](https://github.com/klaufel/awesome-design-systems) 与 [awesome-react-design-systems](https://github.com/jbranchaud/awesome-react-design-systems)。

## 更多公司设计系统

- [Firefox Photon Design System](https://design.firefox.com/photon) - Launch recognizable, enjoyable Firefox products and features faster.
- [Atlassian Atlaskit](https://atlaskit.atlassian.com/) - Atlassian's official UI library built to the Atlassian Design Guidelines.

更多公司 DS 大全见 https://github.com/alexpate/awesome-design-systems

## 更多设计系统资源

- [Design system checklist](https://designsystemchecklist.com/) - Open-source checklist to plan, build and grow a design system.
- [Design Systems Survey](https://designsystemssurvey.seesparkbox.com/) - Survey on design systems across 20+ industries.
- [Design.systems](https://design.systems/) - Resources for the design systems community.
- [Super friendly](https://superfriendlydesign.systems/) - Helping in-house teams make better digital products with design systems.

## 更多 design tokens

- [Awesome Design Tokens](https://github.com/sturobson/Awesome-Design-Tokens) - Big curated list of design tokens resources.
- [Abstract Connect](https://github.com/MichaelZaporozhets/abstractconnect) - Design tokens extractor for devs using Abstract + JavaScript.
- [Zeplin JSON export tokens](https://extensions.zeplin.io/berk/zeplin-json-extension) - Zeplin extension generating design tokens in JSON.

## 更多 pattern library

- [Storybook design system](https://github.com/storybookjs/design-system) - Reference design system built with Storybook.
- [awesome-storybook](https://github.com/lauthieb/awesome-storybook) - More Storybook resources and addons.
- Storybook 核心 addons: a11y / actions / backgrounds / docs / knobs(controls) / links / source / storyshots / viewport — 见 https://storybook.js.org/addons

## 更多 React 设计系统库

- [Atlaskit](https://atlaskit.atlassian.com/) - Atlassian - official React UI library per the Atlassian Design Guidelines.
- [cf-ui](https://cloudflare.github.io/cf-ui/) - Cloudflare - packages to build UIs at Cloudflare with React.
- [Hack Club Design System](https://design.hackclub.com) - React components designed for speed, consistency, and best practices.
- [Mineral UI](https://mineral-ui.com/) - CA Technologies - open-source design system for modern software experiences.
- [MongoDB Design](http://mongodb.design/#/) - MongoDB - design for mission-critical applications.
- [Pivotal UI](https://styleguide.pivotal.io/) - Pivotal - React components styled for the Pivotal brand.
- [Plasma](http://plasma.guide/) - WeWork - design system for building internal business tools.
- [Pluralsight Design System](https://design-system.pluralsight.com/) - UI building blocks for cohesive design across Pluralsight products.
- [Priceline One](https://pricelinelabs.github.io/design-system/) - Priceline - design system focused on speed, consistency, and best practices.
- [Seek Style Guide](https://seek-oss.github.io/seek-style-guide/) - Seek - living style guide powered by React, webpack, CSS Modules and Less.
- [SpareBank 1 Design System](https://design.sparebank1.no/) - SpareBank - a common language for consistent design.
- [Spark Design System](https://sparkdesignsystem.com/) - Quicken Loans - patterns and components for Fintech products.
- [Swarm Design System](https://meetup.github.io/swarm-design-system/) - Meetup - UI components to quickly ship new products and features.
- [Uniform](http://uniform.hudl.com/) - Hudl - components, visual guidelines, language and resources.
- [Lightning Design System React](https://react.lightningdesignsystem.com/) - Salesforce - React implementation of the Lightning Design System.
